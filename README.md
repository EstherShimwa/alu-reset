# ALU RESET

## Description
ALU RESET is a web-based application that provides ALU students with an anonymous space to pause, reflect, and manage emotional stress.

## Features
- Emotional offload text input
- Breathing exercise with timer
- Reflection questions
- Emotion slider
- Support redirection

## How to Run
1. Download or clone the repository
2. Open the project folder
3. Open index.html in your browser
